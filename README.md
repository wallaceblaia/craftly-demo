# Craftly

Order handmade goods from local makers. Built in three weekends with an AI coding assistant.

> ⚠️ **Intentionally insecure demo.** This repository is a fictional "vibe-coded MVP" used to demonstrate ArchGenerator
> reports in an illustrative video scenario. It contains deliberate security and design flaws. **Do not deploy it and do
> not reuse its code.** All keys and passwords in it are fake.

## Run

```
npm install
npm start
```

Then open http://localhost:3000.
